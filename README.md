# MiniBrain v0.2

Модульная браузерная нейросеть для изучения обучения с обратным распространением ошибки.

## Структура проекта

- `index.html` — главная страница и точка входа.
- `styles.css` — оформление интерфейса.
- `src/config.js` — параметры приложения и Supabase.
- `src/brain.js` — архитектура сети, forward pass, backpropagation и Adam.
- `src/app.js` — интерфейс, запуск/пауза обучения, график и облачные действия.
- `src/storage.js` — локальное сохранение, импорт и экспорт.
- `src/supabase.js` — анонимная авторизация и облачная синхронизация.

## Запуск

Открой GitHub Pages или запусти локальный HTTP-сервер из корня проекта. Не открывай HTML через `file://`: браузеру нужен HTTP(S), чтобы загружать JavaScript ES-модули.

## Облачное сохранение

В Supabase включи **Authentication → Sign In / Providers → Anonymous Sign-Ins**. В браузерной конфигурации используется только publishable key. Доступ к записям ограничен RLS-политиками по `auth.uid()`.

Анонимная сессия связана с конкретным браузером. Для переноса прогресса между устройствами позже нужно добавить привязку постоянного способа входа.

## Назначение

Текущая сеть обучается на XOR из четырёх примеров. Это учебный MLP, а не универсальная языковая модель.
