# Фонтан «Титан» — 56,1 м (33 человеческих роста)

Интерактивная 3D-сцена на Three.js: можно ходить по парку, подойти к подножию,
забраться на мост через бассейн и увидеть, как сооружение высотой **56,1 м**
(ровно 33 роста по 1,7 м) возвышается над вами.

## Запуск

Страница использует ES-модули, поэтому её нужно открыть **через локальный сервер**
(открытие `index.html` двойным кликом не сработает — браузер блокирует модули по `file://`).

```bash
# из корневой папки проекта
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

Или одной командой:

```bash
./run.sh
```

## Управление

**Компьютер**

| Клавиша | Действие |
|---|---|
| `W` `A` `S` `D` / стрелки | идти |
| мышь | смотреть (клик по сцене — захват курсора) |
| `Shift` | бежать |
| `F` | режим полёта (`Space` / `C` — высота) |
| `T` | кинематографичный облёт |
| `M` | звук |
| `Esc` | отпустить курсор |

Если браузер не даёт захват указателя — зажмите левую кнопку мыши и двигайте курсор.

**Телефон**

- джойстик слева — идти;
- свайп по экрану — обзор;
- кнопки справа: `БЕГ`, `ПОЛЁТ`, `ОБЛЁТ`, `ЗВУК` (в полёте появляются `▲` / `▼`).

## Что внутри

| Файл | Назначение |
|---|---|
| `index.html` | разметка HUD и стартового экрана |
| `styles.css` | оформление панели, шкалы 33×, мобильные элементы |
| `src/config.js` | единые константы мира (метры, масштаб, палитра) |
| `src/sky.js` | небо-градиент с облаками и солнцем |
| `src/environment.js` | площадь, колоннада, деревья, город, горы, светлячки, птицы |
| `src/fountain.js` | архитектура фонтана: бассейн, островок, чаши, шпиль, кристалл |
| `src/water.js` | вода (шейдер + отражения кубической камерой), струи, брызги, туман |
| `src/player.js` | управление от первого лица, коллизии, полёт, облёт |
| `src/hud.js` | шкала 33×, живые замеры, компас |
| `src/audio.js` | процедурный звук воды (без внешних файлов) |
| `src/touch.js` | мобильное управление |
| `src/main.js` | сборка сцены, цикл, адаптивное качество |

## Масштаб

Рост игрока принят равным **1,7 м**, высота сооружения — `1,7 × 33 = 56,1 м`.
Рядом с табличкой стоит силуэт человека ростом 1,7 м — для наглядного сравнения.

## Производительность

Качество подстраивается автоматически: если кадр стабильно тяжёлый, снижаются
разрешение рендера, размер теневой карты, частота обновления отражений и bloom.
Принудительно: `?quality=low|medium|high`.

## Зависимости

Three.js r160 лежит локально в `vendor/` — интернет при запуске не нужен.
