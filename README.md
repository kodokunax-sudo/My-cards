# Фонтан «Титан» — 56,1 м (33 человеческих роста)

Интерактивный мир на Three.js: стартуйте в небольшом доме у леса, пройдите по грунтовой дороге через лесные зоны и равнины, пересеките реку по мосту и доберитесь до фонтана высотой **56,1 м** (ровно 33 роста по 1,7 м). Радиус игрового мира увеличен в 10 раз.

## Запуск

Страница использует ES-модули, поэтому её нужно открыть **через локальный сервер**
(открытие `index.html` двойным кликом не сработает — браузер блокирует модули по `file://`).

```bash
# из корневой папки проекта
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

Или одной командой:

```bash
./run.sh
```

## Управление

**Компьютер**

| Клавиша | Действие |
|---|---|
| `W` `A` `S` `D` / стрелки | идти |
| мышь | смотреть (клик по сцене — захват курсора) |
| `Space` | прыгать / всплывать в воде |
| `Shift` | бежать |
| `F` | режим полёта (`Space` / `C` — высота) |
| `T` | кинематографичный облёт |
| `C` | нырять в воде |
| `M` | звук |
| `Esc` | отпустить курсор |

Если браузер не даёт захват указателя — зажмите левую кнопку мыши и двигайте курсор.

**Телефон**

- джойстик слева — идти;
- свайп по экрану — обзор;
- кнопки справа: `БЕГ`, `ПРЫЖОК`, `ПОЛЁТ`, `ОБЛЁТ`, `ЗВУК` (в полёте и воде появляются `▲` / `▼`).

## Физика и время суток

Игрок имеет рост 1,7 м, ускорение, гравитацию, прыжок и столкновения с твёрдыми мешами. Плавание использует направление камеры, инерцию и плавучесть: W с взглядом вниз помогает нырять, взгляд вверх помогает всплывать, Space/C управляют вертикальным движением. Глубина фонтана — 28 м; в реке также можно плавать. Под водой запас кислорода составляет 24 секунды, у поверхности он восстанавливается. При полном истощении игрок возвращается в стартовый дом. Новый ландшафт включает лесные зоны, равнины, извилистую реку, переправу, один дом и дорогу к фонтану. Через 3 минуты после входа в парк начинается плавный переход к ночи.

## Масштаб

Рост игрока принят равным **1,7 м**, высота сооружения — `1,7 × 33 = 56,1 м`.
Рядом с табличкой стоит силуэт человека ростом 1,7 м — для наглядного сравнения.

## Производительность

Качество подстраивается автоматически: если кадр стабильно тяжёлый, снижаются
разрешение рендера, размер теневой карты, частота обновления отражений и bloom.
Принудительно: `?quality=low|medium|high`.

## Зависимости

Three.js r160 лежит локально в `vendor/` — интернет при запуске не нужен.
